# Atividade: Criação de uma Página HTML

## Objetivo

Criar uma página HTML simples sobre um tema de sua escolha, utilizando as principais tags e atributos da linguagem HTML.

## Requisitos da página

A página deverá conter, no mínimo:

1. Um título para a página.
2. Um título principal utilizando uma tag de cabeçalho.
3. Pelo menos dois parágrafos de texto.
4. Uma lista ordenada ou não ordenada.
5. Um link para outro site.
6. Uma imagem.
7. Utilização de atributos nas tags, como `href`, `src` e `alt`.
8. Uma estrutura básica de documento HTML, incluindo `html`, `head`, `title` e `body`.

## Sugestões de temas

Você pode criar uma página sobre qualquer assunto de seu interesse, como:

- Hobby.
- Profissão.
- Cidade.
- Filme.
- Esporte.
- Tecnologia.
- Música.

## Entrega

1. Acesse a pasta `projetos-web`.
2. Dentro dela, crie uma pasta específica para esta prática.
3. Crie um arquivo com a extensão `.html` dentro dessa pasta.
4. Desenvolva sua página utilizando os requisitos apresentados.
5. Salve e entregue o arquivo `.html` criado na atividade.

Nome sugerido para a pasta: `pratica-html-basico`

Nome sugerido para o arquivo: `index.html`
